# VAVITTE キックバック（KB）計算ルール 最終確定版
# 作成日: 2026年4月13日
# bomber-admin システム用

---

## ■ 基本計算式

```
KB = 定価 ×（サロン価格率 − 代理店原価率）× 数量
```

---

## ■ 定価の逆算方法

BカートAPIの単価はサロン価格（定価の65%）で登録されている。

```
定価 = BカートAPI最高単価 ÷ 0.65
```

※ 同月・同商品名の最高単価 = サロン1〜5個価格（定価の65%）

---

## ■ 代理店原価率（一律・代理店ごと設定）

| 代理店タイプ | 原価率 | 備考 |
|---|---|---|
| タイプA | 定価 × **45%** | 数量に関係なく一律 |
| タイプB | 定価 × **40%** | 数量に関係なく一律 |

設定場所: 管理画面 → 代理店管理 → 詳細 → KB掛け率（%）

---

## ■ サロン価格率（商品タイプ別）

| 商品タイプ | 判定条件 | サロン価格率 |
|---|---|---|
| 店販用単品 1〜5個 | 「店販用」含む＆数量1〜5 | **65%** |
| 店販用単品 6個以上 | 「店販用」含む＆数量6以上 | **60%** |
| 業務用単品 | 「業務用」含む | **65%（何個でも一律）** |
| エンジェル | セット名に「エンジェル」含む | **65%（何個でも一律）** |
| ミカエル/6+1セット | 「ミカエル」or「6+1」含む | **60%（常に6個計算）** |

---

## ■ 商品タイプ別 KB計算式

### 1. 店販用単品（1〜5個）
```
定価 = 最高単価 ÷ 0.65
KB = 定価 × (0.65 − 代理店率) × 数量
```

### 2. 店販用単品（6個以上）
```
定価 = 最高単価 ÷ 0.65
KB = 定価 × (0.60 − 代理店率) × 数量
```

### 3. 業務用単品 / エンジェル（何個でも）
```
定価 = 最高単価 ÷ 0.65
KB = 定価 × (0.65 − 代理店率) × 数量
```

### 4. ミカエル / 6+1セット
```
単品定価 = セット価格 ÷ 6 ÷ 0.60
KB = 単品定価 × (0.60 − 代理店率) × 6 × セット数
```

## ■ KB早見表（定価¥10,000の商品）

### 代理店原価率 45% の場合

| 商品タイプ | 1個あたりKB | 計算例 |
|---|---|---|
| 店販単品 1〜5個 | **¥2,000** | ¥10,000 × (65%-45%) = ¥2,000 |
| 店販単品 6個以上 | **¥1,500** | ¥10,000 × (60%-45%) = ¥1,500 |
| 業務用/エンジェル | **¥2,000** | ¥10,000 × (65%-45%) = ¥2,000 |
| ミカエル 1セット | **¥9,000** | ¥10,000 × (60%-45%) × 6 = ¥9,000 |

### 代理店原価率 40% の場合

| 商品タイプ | 1個あたりKB | 計算例 |
|---|---|---|
| 店販単品 1〜5個 | **¥2,500** | ¥10,000 × (65%-40%) = ¥2,500 |
| 店販単品 6個以上 | **¥2,000** | ¥10,000 × (60%-40%) = ¥2,000 |
| 業務用/エンジェル | **¥2,500** | ¥10,000 × (65%-40%) = ¥2,500 |
| ミカエル 1セット | **¥12,000** | ¥10,000 × (60%-40%) × 6 = ¥12,000 |

## ■ 判定の優先順位（コード上）

```
1. 代理店にKB掛け率が設定されているか？
   → 未設定なら従来方式（5/13, 1/3）で計算

2. 「ミカエル」or「6+1」を含むか？
   → YES → ミカエル計算（セット価格÷6÷0.60で単品定価逆算）

3. 「エンジェル」or「業務用」を含むか？
   → YES → 常に65%で計算（数量無関係）

4. 上記以外（店販用単品）
   → 数量1〜5個: 65%
   → 数量6個以上: 60%
```

## ■ その他の控除項目（KB清算書）

| 項目 | 計算方法 |
|---|---|
| システム利用料 | KB対象注文件数 × ¥300 |
| 決済手数料 | 対象決済（クレジット/Paid/代金引換）の売上 × 3% |
| 消費税 | (KB合計 − システム利用料 − 決済手数料) × 10% |

## ■ 代理店ごとの追加設定

| 設定項目 | 説明 | 設定場所 |
|---|---|---|
| KB掛け率（%） | 代理店原価率（45 or 40） | 代理店管理 → 詳細 |
| 自社注文を含める | ONなら代理店自身の注文をKB清算に含める | 代理店管理 → 詳細 |
| 固定調整項目 | 業務委託費など毎月の固定加減算 | 代理店管理 → 詳細 |
| 請求書メール | 請求書送付先メールアドレス | 代理店管理 → 詳細 |
